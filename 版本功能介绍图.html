演进路线

每一代都在回答上一代没解决的问题。

V3

会填表，不会拼卷

解决了格式破坏与字段提取，但最终产物仍是散落的 5 张表，律师要手动把表和正文材料合并装订。

V4

能拼出完整卷宗

引入文书切分 + 目录映射，一键产出符合《归档生成标准》的完整 PDF，但仍是单机软件，成果留在本地。

V5

搬上网，团队共用

把 V4 引擎包进 Web 平台，多人登录、集中存储、实时进度，局域网内任意电脑浏览器即可使用。

V6

合并前可核对、可改表

分析完成后进入待核对，浏览器内编辑 5 份 Word 系统表，确认无误再合并 PDF；已完成归档也可回看编辑。

核心结论：V6 = V5 的 Web 协同 + 预览核对闸门 + 在线 Word 编辑。

技术架构

V5 把 V4 的核心模块通过桥接层原样复用，新写的只有 Web 外壳。

V3 / V4 桌面

界面：Python tkinter GUI（打包为 Windows EXE）
OCR：百度 OCR / MinerU 本地 / MinerU API 可切换
引擎：文书切分 + 目录映射 + 模板填充 + PDF 合并
产物：本地文件夹（5 份 Word + 完整 PDF）
  • 单机运行，成果存本地磁盘
  • 单用户，无登录鉴权

V5 Web

前端：Vue3 + Element Plus（SPA）
后端：FastAPI（异步）+ SQLite(WAL)
OCR/LLM：仅 MinerU 云 API + DeepSeek
引擎：sys.path 桥接，零改动复用 V4 全部核心算法
模板：Word COM（win32com）单线程串行填充
  • JWT 登录，多用户多组织
  • WebSocket 实时进度，成果入库集中存储
  • 部署：Windows Server + Word，局域网开放
