# V5 现场演示彩排脚本

> **时长**：3–5 分钟  
> **样本**：`test_sample/test_file/2014-兴泰贸易.pdf`（80 页民事卷，约 5.7 MB，AGENTS.md 基准案）  
> **环境**：`cd web/backend && python run.py` → http://127.0.0.1:8000

---

## 彩排前检查清单

- [ ] 后端已启动，浏览器能打开登录页
- [ ] 系统设置中已配置 **DeepSeek API Key** 和 **MinerU API Token**
- [ ] 服务器已安装 **Microsoft Word**（模板填充必需）
- [ ] 测试 PDF 文件就绪（约 4–5 MB）
- [ ] 网络可访问 MinerU 云 API 和 DeepSeek API
- [ ] 汇报 HTML [`汇报展示.html`](../汇报展示.html) 可在第二块屏幕打开
- [ ] 备用：提前跑完一次任务，用已完成案件演示下载环节（防现场 OCR 超时）

---

## 演示步骤（与汇报第 9 页六步对应）

### 步骤 1 · 登录（15 秒）

1. 浏览器打开 `http://127.0.0.1:8000`
2. 输入账号 `admin` / `admin123`（或律所实际账号）
3. **话术**：「律师不用装任何软件，打开浏览器就能用。」

### 步骤 2 · 新建案件（20 秒）

1. 点击「新建案件」
2. 案件名称填 **`2014-兴泰贸易`**
3. 类型选 **民事**
4. 点击创建，自动进入案件详情页
5. **话术**：「每个案件独立管理，历史成果长期保存。」

### 步骤 3 · 上传文件（30 秒）

1. 上传类型保持 **默认（综合文档）**（路径 A · 单卷综合）
2. 拖拽或选择 `2014-兴泰贸易.pdf`
3. 确认文件列表显示文件名和大小
4. **话术**：「也支持路径 B——多份 PDF 分别标注合同、起诉状、判决书。」

### 步骤 4 · 一键生成（10 秒）

1. 正文排序选 **按目录序**
2. 点击 **「一键生成完整归档」**
3. 自动跳转到进度页
4. **话术**：「点一下，后面全自动。」

### 步骤 5 · 实时进度（2–3 分钟，可边讲边等）

重点展示 **实时日志** 滚动，按顺序讲解：

| 日志阶段 | 讲解要点 |
|----------|----------|
| OCR 识别 | MinerU 云端识别 80 页扫描件 |
| 文书切分 | 自动识别每份文书边界 |
| 目录映射 | 归入 18 项标准目录槽位 |
| 字段提取 | DeepSeek 提取 30+ 字段 |
| 模板填充 | 自动生成 5 份 Word 系统表 |
| 合并归档 | 拼装完整 PDF，页守恒校验 |

**话术**：「每一步都看得见，不用盲等。」

> **若 OCR 超过 3 分钟**：切换到预跑完的已完成案件，直接演示步骤 6。

### 步骤 6 · 下载成果（30 秒）

1. 进度 100% 后展示「归档完成」
2. 点击 **下载完整归档 PDF**
3. 可选：展开「查看已提取的字段值」展示 2–3 个字段
4. 回到案件详情页，展示历史任务可回下载
5. **话术**：「PDF、Word、ZIP 都能下；改字段可以只重填表，不用重新 OCR。」

## 常见问题应对

| 情况 | 应对 |
|------|------|
| API Key 未配置 | 提前在「系统设置」配好；现场勿临时填 |
| 归档失败 | 展示上次成功的历史任务下载；口头说明原因 |
| 网络慢 | 用预跑案件；强调「首次 OCR 最慢，重填模板很快」 |
| 缺失目录项弹窗 | 正好演示「人工闸门」——选「跳过并继续」 |
| Word 未安装 | 提前确认服务器环境；此为部署前置条件 |
